# Menu audio

Sounds are wired in `MenuBootstrap` (composition root) and driven by the same pointer-down hook as the wizard cast (see `RENDERING.md`).

| Event | Trigger | Sound |
| --- | --- | --- |
| Hover | `PointerEnterEvent` (trickle-down on the panel root) whose target is an enabled `Button` | `hover` |
| Press | `PointerDownEvent` / `NavigationSubmitEvent` on an enabled `Button` | `click`, or `back` for `back-button` |
| Cast | Every wizard `Cast()` (`SpellSoundWizardAnimator` decorates `IWizardAnimator`) | random `spellClips` entry, never the same twice in a row |

Hover only counts the `Button` itself: its children raise their own enter events while the pointer is already inside, so they are ignored.

## Swapping sounds

Edit `Assets/_Project/Audio/MenuAudioLibrary.asset` in the Inspector: clip and volume per slot, plus the spell clip list and volume. No code change needed. Any number of spell clips works.

Import settings used: UI `.ogg` mono, Decompress On Load, Vorbis 70%; spell `.wav` mono, Compressed In Memory, Vorbis 70%.

## Scene

- `MenuUI` has the UI `AudioSource` (2D).
- The wizard root (the object with the `Animator`, not its FBX child of the same name) has the spell `AudioSource` (2D).
- `MenuCamera` keeps the `AudioListener`.

## Music

Two looping layers play together under the `MenuMusic` object (`Theme` and `Ambient` `AudioSource`s, 2D, loop, play on awake off):

| Layer | Clip | Source |
| --- | --- | --- |
| Theme | `Audio/Music/MenuTheme.wav` | Original chip-style loop (D Phrygian dominant, 84 BPM, 91.4 s) generated by `art/audio/compose_menu_theme.py` |
| Ambient | `ThirdParty/OpenGameArt/CathedralInTheForest/cathedral_forest.ogg` | CC0, see `ASSET_CREDITS.md` |

Both clips are imported as Streaming, Vorbis quality 0.6 (the theme is mono, the ambient track stereo). `MenuAudioLibrary` holds `themeVolume` (0.55), `ambientVolume` (0.45) and `musicFadeInSeconds` (2.5). `MenuMusicPlayer` (pure, driven by `Tick`) fades both layers from silence to their targets; `UnityMusicLayers` starts them with `PlayScheduled` on a shared dsp time so they stay aligned. `MenuBootstrap` wires it and does nothing if the library or either source is missing.

Regenerate the theme with `python art/audio/compose_menu_theme.py <out.wav>` and replace `MenuTheme.wav`.

## Mixer

Not created yet: `AudioMixerController` is internal and cannot be built from scripts. Create `Audio/HexFallMixer.mixer` in the editor (Assets > Create > Audio > Audio Mixer), add `Music` and `SFX` groups under `Master`, expose `MusicVolume` and `SfxVolume`, and set each `AudioSource`'s Output (UI and spell sources to `SFX`, music sources to `Music`).

## Web

Browsers block audio until the first user gesture, so hover sounds before the first click are silent in WebGL. On WebGL the music starts on the first pointer down, key press or submit and fades in from that moment; in the editor and desktop builds it starts immediately.
